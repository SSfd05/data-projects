## 1. 分层结果

| 层 | 表 | 行数 |
| --- | --- | --- |
| ODS | `ods_retail`（原始落地） | 541,909 |
| DWD | `dwd_order_detail`（清洗后明细） | 522,570 |

清洗保留了 96.4% 的记录，丢弃的是退货单、负数量、零单价和没有客户 ID 的行。

## 2. 核心指标

- GMV：**10,272,179**
- 订单数：**19,776**，客户数：**4,334**
- 客单价：**519.43**
- 复购率：**65.3%**（下单 ≥2 次的客户占比）
- 退货金额占比：**7.0%**
- 覆盖月份：**13** 个月；GMV 最高的国家是 **United Kingdom**

## 3. 为什么这么分层

- **ODS 不做任何清洗**：原始数据永远是唯一事实来源，出问题可以回溯。
- **DWD 做清洗和维度建模**：把退货单、负数量这些脏数据挡在这里，下游全部不用再判断。
- **DWS 按主题预聚合**：客户维度和商品维度各自汇总，避免 ADS 层重复算。
- **ADS 只放业务口径**：每个指标只在一处定义，避免“同一个复购率三个部门三个数”。

## 4. 口径说明

- 复购率 = 下单次数 ≥ 2 的客户数 / 有客户 ID 的客户数；
- 退货金额占比 = 退货单金额绝对值 / 正常销售金额；
- 客单价 = GMV / 订单数（订单按 InvoiceNo 去重）。
